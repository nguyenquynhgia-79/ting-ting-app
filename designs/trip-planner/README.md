# 🎨 Thiết Kế UI — TingTing Trips

Thư mục này chứa toàn bộ thiết kế mockup cho tính năng **Trip Planner** (TingTing v2).

## Danh sách màn hình

| File | Màn hình | Trạng thái |
|:---|:---|:---|
| `01-create-trip.png` | Tạo chuyến đi — Step 1 (Thông tin + Chọn mode) | ✅ Đã duyệt |
| `02-ai-preferences.png` | Nhập sở thích nhóm (AI mode — Step 2) | ✅ Đã duyệt |
| `03-trip-timeline.png` | Màn hình Timeline chi tiết (Dùng chung cả 3 mode) | ✅ Đã duyệt |
| `04-place-search-modal.png` | Modal tìm kiếm địa điểm Google Maps | ✅ Đã duyệt |

## Hướng dẫn lưu file

1. Export từ Stitch dưới dạng PNG (2x resolution cho mobile).
2. Đặt tên file theo quy tắc `XX-ten-man-hinh.png` (XX = số thứ tự 2 chữ số).
3. Commit vào nhánh `feature/v2-upgrade` cùng với code.

## Ghi chú thiết kế

- **Màu chính (Primary):** `#10B981` (Emerald Green)
- **Nền trang (Background):** `#F9FAFB`
- **Nền card (Surface):** `#FFFFFF`
- **Font:** System UI / Inter
- **Bo góc card:** 16px
- **Không dùng shadow** — chỉ dùng border `1px solid #E5E7EB`
